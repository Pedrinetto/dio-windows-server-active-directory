## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio prático da plataforma **DIO.me**, com o objetivo de criar um Segundo Cérebro utilizando Inteligência Artificial por meio do Google NotebookLM.

O tema escolhido foi **Windows Server e Active Directory**, tecnologias fundamentais para o gerenciamento de redes, usuários, computadores e recursos em ambientes corporativos.

O projeto utiliza fontes técnicas confiáveis, incluindo documentações oficiais da Microsoft e conteúdos educacionais em vídeo, permitindo que a IA responda perguntas com base nos materiais selecionados.

## 🎯 Objetivo

Criar um assistente de estudos especializado em Windows Server e Active Directory, capaz de explicar conceitos, orientar procedimentos administrativos e auxiliar no diagnóstico de problemas relacionados à infraestrutura de TI.

O notebook foi planejado para apoiar o aprendizado desde conceitos fundamentais até atividades de administração de ambientes corporativos.

## 🧠 Ferramenta Utilizada

**Google NotebookLM (Gemini Notebook)**

A ferramenta permite:

- Consultar informações de fontes selecionadas.
- Fazer perguntas e receber respostas com citações.
- Estudar documentações técnicas.
- Criar mapas mentais.
- Gerar apresentações.
- Produzir materiais de revisão.
- Organizar conhecimentos técnicos.

### Critérios de seleção

As fontes foram selecionadas considerando:

- **Confiabilidade:** prioridade para documentação oficial da Microsoft.
- **Relevância:** conteúdos aplicáveis à administração de servidores.
- **Qualidade técnica:** explicações fundamentadas e exemplos práticos.
- **Diversidade:** documentação web, conteúdo educacional e vídeos.
- **Aplicabilidade:** conhecimentos úteis para ambientes corporativos.

## ⚙️ Diretrizes de Comportamento da IA

O notebook foi configurado para atuar como um especialista em Windows Server e Active Directory.

As principais diretrizes definidas foram:

1. Responder sempre em português brasileiro.
2. Utilizar prioritariamente as fontes cadastradas.
3. Apresentar referências e citações.
4. Explicar conceitos do básico ao avançado.
5. Fornecer procedimentos técnicos passo a passo.
6. Auxiliar no diagnóstico de problemas de infraestrutura.
7. Explicar comandos e suas finalidades.
8. Priorizar segurança e boas práticas administrativas.
9. Não inventar procedimentos ou funcionalidades.
10. Propor exercícios para reforçar o aprendizado.
